<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server module -> browser bundle | Any module reachable from a Client Component's import graph is shipped to the browser. Upstream base URLs and the OpenSky OAuth2 client credentials must never cross this boundary. |
| repository -> reviewer | README.md and REQUIREMENTS.md are read by someone who will not read the source; a false claim in either is a correctness failure of the deliverable, and a leaked value in either is an information disclosure. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Information Disclosure | `opensky.client.ts`, `nasStatus.client.ts`, `faaFacility.client.ts` — hold `TOKEN_ENDPOINT`, `FLIGHTS_BASE`, `NAS_FEED_URL`, `ARCGIS_BASE`, and (transitively via `env.ts`) the OpenSky client credentials | high | mitigate | Task 1: `import 'server-only';` on line 1 of each, converting transitive protection into a module-boundary failure in any client or SSR bundle (D-01). |
| T-05-04 | Information Disclosure | README.md, REQUIREMENTS.md — submission-facing documents | high | mitigate | Tasks 2 and 3 reference environment variable *names* and endpoint hostnames only. No credential value, no `.env.local` content, and no bearer token is written into either file. |
| T-05-05 | Tampering (SSRF) | `validate.ts` shape gate ahead of every adapter URL construction | medium | accept | Format-only validation is the accepted state after the 2026-08-13 pivot; Task 3 documents it truthfully rather than overstating it. Reinstating a registry allowlist is out of scope. |
| T-05-07 | Denial of Service (regression) | The three colocated `*.client.test.ts` suites, which import the newly guarded modules | medium | mitigate | Both vitest configs already alias `server-only` to `test/stubs/server-only.ts`; Task 1's gate is a full `npm test` run, so a broken suite blocks the change rather than shipping. |
| T-05-SC | Tampering (supply chain) | npm dependencies | low | accept | This plan installs nothing. `server-only@^0.0.1` is already a declared dependency and is already imported by four source files; no package-manager install task exists, so no legitimacy checkpoint applies. |

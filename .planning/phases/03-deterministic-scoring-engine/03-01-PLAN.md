## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller → `fetchFaaFacility(icao)` | The airport code originates from analyst text upstream and is untrusted until `isValidIcao` runs; it is then interpolated into the facility query's `where` clause. |
| ArcGIS facility response → `fetchRunwayRows` | The `ARPT_ID` field returned by the FIRST query is untrusted third-party data and is itself interpolated into a SECOND outbound query's `where` clause — a distinct injection surface from the caller-supplied `icao`. |
| ArcGIS response → app memory | Runway/facility attributes (name, coordinates, codes) enter the cache and later feed the scoring engine (plan 03-02) after only basic type coercion. |

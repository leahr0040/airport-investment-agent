Write `src/domain/adapters/isolation.test.ts`. This test file exists to exercise the two adapters together, which is the only way the phase-level claim in ROADMAP criterion 4 gets proven — each adapter's own suite can only show that it fails cleanly by itself.

Stub the network with a single `vi.stubGlobal("fetch", vi.fn())` whose implementation routes on the requested URL: requests to the OpenSky hosts behave one way, requests to the FAA host another, so a single test can script one source healthy and the other broken. Call `clearCache()` and `clearTokenCache()` in `beforeEach`.

Cases:
1. OpenSky times out, FAA succeeds — await both adapters through `Promise.all` for the same airport. Assert the OpenSky result is ok false with reason `timeout`, the FAA result is ok true, and that `Promise.all` itself resolved rather than rejecting. The last assertion is the point: an adapter that threw would reject the combined await and take the whole answer down with it.
2. FAA errors with HTTP 503, OpenSky succeeds — the mirror case. Assert the FAA result is ok false with reason `error` and the OpenSky result is ok true with its movement counts intact.
3. Both sources fail — both results are ok false with their own reasons, and the combined await still resolves. Two simultaneous failures must still be reportable rather than fatal.
4. Malformed identifier reaches both adapters — both return ok false with reason `invalid_input` and the fetch mock was never called at all. This shows the format gate short-circuits every adapter before any I/O.
5. Failure is not cached — after case 1's OpenSky timeout, re-script the mock so OpenSky succeeds and call it again within the same time window; assert the second call returns ok true. A transient 3-second blip must not blank that KPI for the whole TTL, which is what D-06's hard-fail contract implies when combined with the cache never storing rejections.
6. No stale branch reaches a caller — assert that a failed result has no `data` property and a successful one has no `reason` property, so the discriminated union is genuinely exclusive and downstream code cannot accidentally read half-populated state. D-06 removed the stale path deliberately; this pins it.

Add a file-header comment stating in one line that this file exists to prove ROADMAP Phase 2 criterion 4, so a future reader does not mistake it for a duplicate of the per-adapter suites.

1. Create `vitest.smoke.config.ts`:
   - `test.include` set to a pattern matching only `src/**/*.smoke.ts`, which does not overlap the default config's `src/**/*.test.ts`. This non-overlap is the safety property that keeps live calls out of `npm test`.
   - `resolve.alias` mirroring the default config exactly: the `@` alias to `src`, and `server-only` to the stub in `test/stubs/`.
   - `environment` set to node, and `testTimeout` raised to 60000 to accommodate two real upstreams behind a 3-second per-request timeout plus a token exchange.
   - Real credentials: populate `test.env` from the repo's dotenv files by calling vite's `loadEnv` helper with an empty prefix so every variable is picked up, not just prefixed ones. If `vite` is not resolvable as a direct import from the config file, fall back to changing the npm script to run node with its `--env-file` flag pointed at `.env` instead. Either way, no credential value is written into any committed file.

2. Create `src/domain/adapters/live.smoke.ts` as a Vitest file that hits the real services. Use `KATL` as the primary target — a large hub guaranteed to have movements and to appear in FAA data when disrupted. Structure:
   - Call `clearCache()` first so the counters start clean.
   - OpenSky: call `fetchMovements("KATL")`. Assert the result is ok true. If it is ok false, the assertion message must include the returned reason and detail, since that is the whole diagnostic value of this run. Assert `departureCount` and `arrivalCount` are numbers, assert the reported window is 86400 seconds wide, and assert `fetchedAt` parses as a date.
   - FAA: call `fetchNasStatus("KATL")`. Assert ok true. Do NOT assert a non-empty event list — an airport with nothing wrong is the normal case and the correct answer; assert only that `events` is an array and `lid` is ATL.
   - Cache proof: record `getCacheStats()`, call both adapters a second time for the same airport, and assert the hit counter increased by exactly 2 while the miss counter did not change. This is DATA-04 observed against live traffic rather than inferred.
   - Isolation proof against a real failure: call `fetchMovements` with a syntactically valid but non-existent ICAO code and assert the result is ok false rather than a thrown error.
   - The file must print no credential, token, or raw response body. Reporting a count or a status is fine; dumping a response is not.

3. Add a `smoke` entry to the scripts block in `package.json` running Vitest once against the smoke config. Leave `test`, `test:watch`, `typecheck`, `lint`, `build`, `dev`, `start`, and `postinstall` unchanged.

If the OpenSky OAuth2 client has not been registered yet, this run is where that surfaces — STATE.md lists it as a blocking prerequisite for this phase. A failure at the token step is expected and actionable in that case; do not add a fallback or a degraded path (v1 has none by explicit project decision).

<objective>
Carry the ICAO code as data on every entry in Phase 1's hardcoded region/metro lookup table (D-09), and derive ICAO by rule only on the passthrough branch where no table row exists (D-10).

Purpose: OpenSky addresses airports by 4-letter ICAO code (`KATL`), while `REGION_LOOKUP` currently holds only 3-letter IATA codes. The FAA ArcGIS registry that used to supply the `ARPT_ID`↔`ICAO_ID` join was deleted in the 2026-08-13 Phase 1 architecture pivot, so there is no live source for that mapping anywhere in the codebase. D-09 fixes this at the data level rather than by inventing a derivation rule that would be wrong for Alaska, Hawaii, and any airport whose IATA code was renamed independently of its ICAO code.

Output: `lookupAirports()` returns `{iata, icao}` pairs, ready for both adapters in wave 2.
</objective>

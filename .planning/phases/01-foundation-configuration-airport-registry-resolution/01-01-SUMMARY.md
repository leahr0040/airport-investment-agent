**4. [Rule 2 - Missing Critical] Added `postinstall: next typegen` script**
- **Found during:** Task 2, Step 6 (scripts) / verification
- **Issue:** `npx tsc --noEmit` failed with `Cannot find name 'LayoutProps'` — Next.js 16's typed-routes feature generates ambient `LayoutProps`/`PageProps` types into the gitignored `.next/types/` directory, which does not exist until `next dev`, `next build`, or `next typegen` has run once. The plan's must_haves truth requires `npm install` on a fresh clone plus `npx tsc --noEmit` to report zero errors, with no mention of a required `dev`/`build` step first.
- **Fix:** Ran `npx next typegen` to generate the types, then added `"postinstall": "next typegen"` to `package.json` `scripts` so a fresh `npm install` regenerates them automatically.
- **Files modified:** `package.json`
- **Verification:** `npx tsc --noEmit` exits 0 immediately after `npm install` with no other Next.js command run first.
- **Committed in:** `acc9c5a` (Task 2 commit)

**5. [Rule 1 - Bug] `RegionName`/`MatchKind` union literals switched from double to single quotes**
- **Found during:** Task 3 verification
- **Issue:** The plan's automated verification script checks for single-quoted string literals (e.g. `'New England'`); the first draft used double quotes and failed the check.
- **Fix:** Rewrote both union types with single-quoted literals to match the plan's exact verification contract.
- **Files modified:** `src/domain/airports/types.ts`
- **Verification:** Custom verification script (see D4 above) passes.

<objective>
Fetch the FAA ArcGIS facility and runway layers at startup, join them, derive parallel-runway
geometry, and freeze the result as the in-memory canonical airport registry that every later
phase treats as its SSRF allowlist.

Purpose: DATA-01, and the data half of RESOLVE-02 and SEC-02. Phase 1's resolver is only as
correct as the registry underneath it — a registry that is ten times too large (the unguarded
Part 139 filter), that silently drops Alaska, or that carries no runway separation, breaks the
resolver and the Phase 3 scoring engine simultaneously.

Output: `fetchArcGis.ts`, `geometry.ts`, `registry.ts`, three test suites including a live
integration test, and the extended boot hook.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| FAA ArcGIS FeatureServer → registry build | A third-party HTTP response crosses into process memory; its free-text fields later reach both the LLM context and the UI |
| registry build → every Phase 2+ outbound adapter | The registry's key set is the SSRF allowlist; its correctness bounds every later request |
| boot sequence → request serving | A registry that failed to build must not leave the server accepting requests with an empty allowlist |

|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-15 | Tampering | `getRegistry()` returning an empty registry before initialisation | high | mitigate | `getRegistry()` throws `RegistryNotInitialisedError` rather than returning an empty object. An empty registry is an empty allowlist; a caller that treats "no entries" as "nothing to check" would pass every identifier. Asserted by an offline unit test. |
| T-01-16 | Tampering | free-text `ARPT_NAME` / `CITY` from ArcGIS entering LLM context and UI in later phases | high | mitigate | Every row is parsed through a Zod schema that trims, caps string length at 120 characters, and rejects strings containing ASCII control characters. | T-01-17 | Tampering | over-permissive facility filter producing a 10x-too-large allowlist | high | mitigate | `FACILITY_WHERE` pairs `IS NOT NULL` with `<>''` (the Esri empty-string trap), and a client-side `STATE_TO_REGION` membership check enforces the 50-states-plus-D.C. scope independently of the SQL clause.
